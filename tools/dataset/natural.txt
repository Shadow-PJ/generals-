# Natural orders for testing translators (session 3B), written by hand by Claude.
#
# "== <order>" starts a group. The order is phrased so the rule parser reads it, and the card it
# reads is the expected card for every sentence below it, up to the next "==". The sentences say
# the same thing the way players might: slang, typos, missing punctuation and long orders.
# Conventions, the same as the rule parser's:
#   - a step with no subject is done by everyone ("rangers fall back, then attack" = everyone attacks)
#   - "him", "her", "it" and "them" after a condition mean the unit that set it off
#   - hurt and wounded = 50% HP, in trouble = 40%, low and weak = 30%; "group up" = 3 enemies
# Lines starting with "#" are comments.
