show the game without sound, and every idea needs to read on screen. Record at 1920 × 1080,
60 fps, from the desktop app (the battle runs at 20 ticks a second and draws every frame
between them, so it records smoothly). Use the game's own music: the battle theme for the
fights, the rulers' theme for the boss.
